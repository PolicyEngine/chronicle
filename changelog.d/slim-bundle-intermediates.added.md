Add `chronicle build-bundle --slim` (`build_bundle(..., keep_suite_intermediates=False)`), which deletes each source suite's `source_rows.jsonl`, `source_cells.jsonl`, `facts.jsonl` and `ledger.db` as the suite finishes and lists them in `reports/pruned_intermediates.json`; slim mode changes no file the bundle keeps. The full-bundle test and the documented bundle commands use it, and the docs build each bundle in a fresh `mktemp -d` directory instead of a shared `/tmp` path.
