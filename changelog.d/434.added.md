Add SSA Annual Statistical Supplement 2025 Tables 7.B3 and 7.B7 from SSA's section 7.B workbook. The Table 7.B3 package emits December 2024 recipients of federal SSI and of federally administered state supplementation, with their average monthly payments, and the Table 7.B7 package emits calendar 2024 payments of each. Both emit these figures for the nation and by state, except Table 7.B3's national state supplementation figures. Table 7.B7's Total column repeats Table 7.B1's payment totals, so its package leaves that column out. The label register lists the 52 area values the two packages share.
