`publish-raw`, `fetch-artifact` and `publish-derived` upload files above Wrangler's 300 MiB limit to R2 through its S3-compatible API (chronicle#409). Each file goes up as a multipart upload in 100 MiB parts, with one part in memory at a time, and a failed part is retried on its own. A raw or fetched file is not sent again when R2 already holds an object of its size under its key, which carries its sha256. Every file is hashed a chunk at a time instead of being read whole, and `fetch-artifact` streams downloads to disk.
